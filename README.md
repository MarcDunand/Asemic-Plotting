# Asemic-Plotting
Research into generating convincing asemic script capable of being plotted on an Axidraw

<br><br>

# To generate your own asemic script:

1: In the command line, navigate to where you saved this repo

2: Install vsketch
    This can be done by running "pip install vsketch" in the command line

3: Run "vsk run sketch_asemic.py"

4: To save a .svg of what you generate, press the "like!" button in the bottom right hand corner of the window that opens when you run the script

<br><br>

# To change what your asemic script looks like

1: Open sketch_asemic.py in your favorite code editor

2: Near the top there is a long list of commented variable for you to play around with
  Whenever you save the file, vsketch will update the resulting asemic script automatically
